01 / 事業概要

CSCAM独自技術で完成させた
リニアモーター搬送システム。

CSCAM株式会社はサーボ制御、制御通信、PLC統合及び運転ソフトウェアなどの独自技術により、優れた搬送システムを開発しています。LMSシステムは直接的な物理接触なしで各キャリアを独立駆動し、柔軟な搬送環境を実現します。

01SOLUTION

LMSソリューション

Linear Motion System · LCSシリーズ

LMSソリューションは組立・検査ラインに向けた高速高精度キャリア搬送方式です。各キャリアを個別制御でき、混流生産、工程分岐、差別化速度などスマートファクトリー搬送制御を実現します。クリーンルーム、真空、不活性ガス、高温及び薬品暴露などの特殊環境下でも運転可能です。ほぼ任意の形状の軌道を構成できる能力により、物流自動化レイアウトに革新をもたらします。CSCAM独自のサーボ・モーション制御技術に基づき、高速小型物流から大容量重量物物流まで、用途に合わせたソリューションを提供します。

02 / LMSソリューション

ケーブル不要、キャリア独立駆動の
可動磁石式物流システム。

キャリア搬送は各コイルが順次連続動作することで実現され、キャリア位置制御は入口部のホールセンサーに基づいて行われます。従来のコイル(モーター)方式とは異なり、磁石アレイがキャリアに取り付けられキャリアと共に移動します — この構造により追加の外部位置検出センサーが不要です。

LMS(リニアモーター搬送システム)の利点
  • 真空環境下でもケーブルレスのキャリア搬送が可能
  • 高温及び特殊環境下で複数のキャリアに対し独立した高速高精度位置制御が可能
  • ホールセンサーによる非接触キャリア位置検出 — 追加のエンコーダ不要
  • 直線軌道だけでなく、円形・楕円軌道、エレベーター及び横搬送にも対応
  • キャリアが待機不要で生産効率を最大化、ほぼ任意の形状の軌道により物流自動化レイアウトに革新をもたらす

LMS SOLUTION CONFIGURATION

  3. 031台のPLCで最大3台のCPACK制御ユニットを接続可能。

03 / LMS製品

高温、高真空及びその他の特殊環境向けに
設計されたLMS製品ライン。

CSCAMはLMSコイル、専用ドライバ及びEtherCATマスターソフトウェアなど全コンポーネントを自社で生産・提供しています。汎用ラダーロジックによるPLC制御で、他工程との連携・統合が容易です。LMSコイルはデュアルホールセンサーを内蔵し精密な位置制御を実現、コイル設計はコンパクトかつ放熱性能を最適化しています。冗長化されたEtherCAT通信配線により通信断線にも対応、専用通信コアはカスタム開発にも対応しています。

PLCとHMI

  • オペレーターHMI画面設計(Profaceなど)
  • 1台のPLCで最大3台のCPACK制御ユニットを接続可能
  • イーサネット(MX component)通信

CPACK:制御ユニット

  • 1台のCPACK制御ユニットで最大255台のドライバを接続可能
  • 上位ホスト(MXComponent)との共有メモリ通信に対応
  • 下位ドライバとのリアルタイムEtherCAT通信を実現

LMSパッケージ型ドライバ

  • 2chエンコーダ入力(BiSS-C)、EtherCAT CSVモード
  • 主回路:AC200~230V +10~-15% 50/60Hz
  • パッケージ型ドライバ:最大4台の2~3kWドライバを接続可能
  • 単独LMSドライバ(400W、800W、1.5kW、2kW、3kW)にも対応

LMSコイル/マグネット

  • LMSコイルシリーズ(幅30/50/100、長さ200/260/380)
  • エアギャップ:1~5mm · 磁極ピッチ:30mm
  • スキュー角:19.5°(30T) · 6°(50T) · 4°(100T)
