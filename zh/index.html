LMS解决方案

Linear Motion System · LCS系列

LMS解决方案是面向组装与检测产线的高速高精度载具搬送方案。每个载具均可独立控制,可实现混线生产、工艺分支、差异化速度等智能工厂搬送控制。同时可在洁净室真空、惰性气体、高温及化学暴露等特殊环境下运行。凭借可组成几乎任意形状轨道的能力,推动了物流自动化布局的创新。基于CSCAM自主伺服与运动控制技术,提供从高速小件物流到大批量重载物流的量身定制方案。

02 / LMS解决方案

无需线缆、独立驱动载具的
动磁式物流系统。

载具搬送通过各线圈依次连续动作实现,载具位置控制则基于入口处的霍尔传感器完成。与传统线圈(电机)方式不同,磁铁阵列附着于载具并随载具一同移动 — 这一结构无需额外的外部位置检测传感器。

LMS(直线电机搬送系统)优势
  • 即使在真空环境中也可实现无线缆载具搬送
  • 在高温及特殊环境下对多台载具实现独立的高速高精度位置控制
  • 采用霍尔传感器进行非接触式载具位置感应 — 无需额外编码器
  • 不仅支持直线轨道,还支持环形、椭圆轨道、电梯及横向搬送
  • 载具无需等待,最大化生产效率,并可通过几乎任意形状的轨道实现物流自动化布局创新

02-2 / LMS性能
PERFORMANCE
  • 宽广的负载与搬送范围:覆盖从小件到最大1.5吨重载的广泛范围。
  • 高速搬送:以最高5m/s的速度搬运大型重载物品,实现优异的性价比与生产效率。
  • 极端环境下的可靠性:除标准钕铁硼磁铁(70°C)外,还提供支持最高150°C运行的高温磁铁选配(钐钴磁铁)。
  • 宽气隙:1–5mm的宽裕气隙可灵活吸收装配公差,即使轨道存在轻微污染或变形也能保持稳定运行。

03 / LMS产品

专为高温、高真空及其他特殊环境
打造的LMS产品线。

CSCAM自主生产并提供LMS线圈、专用驱动器及EtherCAT主站软件等全部组件。通过通用梯形图逻辑进行PLC控制,可轻松实现与其他工艺的互联与集成。LMS线圈内置双霍尔传感器以实现精确位置控制,线圈设计紧凑并针对散热进行了优化。冗余的EtherCAT通信布线可应对通信线路中断,专有通信内核也支持定制开发。

PLC与HMI

  • 操作员HMI画面设计(如Proface)
  • 单台PLC最多可连接3台CPACK控制单元
  • 以太网(MX component)通信

CPACK:控制单元

  • 单台CPACK控制单元最多可连接255台驱动器
  • 支持与上位主机(MXComponent)进行共享内存通信
  • 与下位驱动器实现实时EtherCAT通信

LMS封装式驱动器

  • 2通道编码器输入(BiSS-C),EtherCAT CSV模式
  • 主电路:AC200~230V +10~-15% 50/60Hz
  • 封装式驱动器:最多可连接4台2~3kW驱动器
  • 同时支持独立LMS驱动器(400W、800W、1.5kW、2kW、3kW)

LMS线圈/磁铁

  • LMS线圈系列(宽度30/50/100,长度200/260/380)
  • 气隙:1~5mm · 磁极间距:30mm
  • 偏斜角:19.5°(30T) · 6°(50T) · 4°(100T)
